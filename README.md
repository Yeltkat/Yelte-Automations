# Yelte-Automations

Practical Python automation samples: spreadsheet cleaning, web scraping, and API integrations that turn hours of manual work into a one-click script.

Each folder below is a small, working example of a service I offer as a freelancer. Every demo includes sample input, the script, and the resulting output, so you can see exactly what you would get.

## What's inside

| Demo | What it does | Typical use |
|------|--------------|-------------|
| [`excel-cleaner/`](./excel-cleaner) | Cleans messy Excel/CSV files: removes duplicates, fixes formatting, merges files, and exports a tidy report | Exports from webshops, CRMs, or accounting tools that need cleaning every week |
| [`web-scraper/`](./web-scraper) | Collects structured data from public websites and saves it to CSV or Excel | Price monitoring, product catalogs, public directories |
| [`form-to-sheets/`](./form-to-sheets) | Connects a form or app to Google Sheets automatically via an API | Sending new orders, signups, or leads to one place without copy-pasting |

## Tech stack

- Python 3.10+
- pandas and openpyxl for spreadsheet work
- requests and BeautifulSoup for scraping
- Google Sheets API and other REST APIs for integrations

## Running a demo

```bash
git clone https://github.com/Yeltkat/python-automation-portfolio.git
cd python-automation-portfolio/excel-cleaner
python -m venv venv
source venv/bin/activate   # On Windows: venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

Each folder has its own README with specific instructions and before/after examples.
